# Gereksiz Özür Makinesi

## Dünyanın En Ciddi Gereksiz Projesi

Bu repository, insanlık tarihinin en büyük sorununa çözüm getiriyor: **Yeterince özür dilememek.**

Artık her şey için, hiçbir şey için, hatta özür dilediğin için bile özür dileyebilirsin. Bu Python scripti, rastgele ama son derece samimi özürler üretir. Bilimsel olarak kanıtlanmıştır ki (kanıt yok), bu makineyi çalıştırdıktan sonra vicdanın %300 rahatlar.

### Nasıl Çalıştırılır?

```bash
python ozur_makinesi.py
```

Script sonsuz döngüde çalışır çünkü özür dilemek de sonsuz bir süreçtir. CTRL+C ile çıkabilirsin ama çıktığın için özür diler.

### Özellikler

- Gerçekten çalışır.
- Türkçe özür diler (diğer dillerde özür dilemeyi bilmez, özür diler).
- Bazen kullanıcıdan onay ister, bazen istemez.
- Hiçbir şey yapmaz ama çok önemliymiş gibi yapar.

### Uyarı

Bu yazılımı kullanmak tamamen sizin sorumluluğunuzdadır. Ortaya çıkacak aşırı samimiyet nedeniyle sosyal ilişkileriniz bozulabilir. Biz özür dileriz.
